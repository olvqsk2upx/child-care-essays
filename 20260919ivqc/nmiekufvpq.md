# 身体正常可以在国内选择三代试管三代试管吗？

> 更新时间：2026-09-19 (UTC+8)

在国内做不是所有人都可以做第三代试管婴儿的，必须要符合做第三代试管的条件才行。身体健康是不能做三代试管的，只有染色体异常、不孕不育的患者才可以做第三代试管婴儿。并且染色体异常、不孕不育夫妇需要具备结婚证、夫妇身份证及准生证，作为依据进行有效的登记才能做试管婴儿。目前国内的三代试管婴儿除患有特殊遗传病是不允许助孕的，有性别需求只能去国外做试管。

## 第三代试管适应人群

第三代试管婴儿也称胚胎植入前遗传学诊断（PGD），指在IVF-ET的胚胎移植前，取胚胎的遗传物质进行分析，诊断是否有异常，筛选健康胚胎移植，防止遗传病传递的方法。目前国家规定只有满足以下要求其中一项才予以三代试管技术助孕。

- 1. 年龄大于35岁，想要生育的患者；
- 2. 自然流产≧3次，排除子宫或内分泌因素；
- 3. 生育过染色体异常疾病患儿的夫妇；
- 4. 3次以上移植未孕者(包括新鲜及冷冻移植)；
- 5. 染色体数目及结构异常的夫妇，如罗氏易位，部分克氏综合症等。

## 第三代试管三代试管需符合的条件

虽然国内做三代试管政策上是限制了性别选择，但也有例外的情况，比如红绿色盲，只能三代试管或者女孩的时候，可以通过第三代试管婴儿技术去助孕，技术是有的，只针对特殊的人群。

**1、X连锁隐性遗传病**

对于这类遗传性疾病，携带致病基因的女性一般是无症状携带者，而男性会发病。在基因诊断不明或者技术条件不允许时，可以进行选择生育女孩，而避免疾病的发生。

**2、X连锁显性遗传病**

对于男方患有X连锁显性遗传病者，可以通过PGD选择生育男孩，从而阻断致病基因在家族中的传递。

**3、Y染色体连锁遗传病**

对于Y染色体连锁的遗传性疾病，只会遗传给男性后代，可以选择生育女性，避免疾病传递给后代。

综上所述，试管婴儿技术确实可以做到性别选择，但是在我国必须有医学指征，非医疗目的的性别选择是违法的。
