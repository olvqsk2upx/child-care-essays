# *没有活力怎么办 能治好吗

> 更新时间：2026-09-11 (UTC+8)

备孕半年，一直没有反应，去检查是我老公的问题，医说他存活率低，活率二十多，畸形率九十多。想咨询下没有活力怎么办？能治好吗？

活力低下，也就是弱精症，需要及时去医院进行治疗，对于弱精症患者，中医和西医有着不同的治疗方案：

西医治疗：

1. 精索静脉曲张引起无精症需要通过手术治疗；

2. 殖道炎症则需要通过消炎治疗；

3. 如果是抗免疫性弱精症，就需要针对免疫因素进行治疗；

4. 如果是先天性弱精，要治疗好比较困难，如果想怀孕，可以选择试管婴儿。

对于弱精症可每日服用一片维素E；口服施尔康，每日一片。

中医治疗：

中医将弱精症分为肾气不足、气血两虚、肝郁血瘀等病症，对于不同的病症，治疗方案是不一样的，如：治疗肾气不足就补益肾气，针对肝郁血瘀的话，就是疏肝活血化瘀等；除此之外，还可配合针灸进行治疗，但效果因人而异。

弱精症是有自然怀孕的可能性的

我老公应该不是先天的，因为之前怀过一次，但是还没做好准备，就去做了人流，想知道活力低，也就是弱精症是什么原因引起的呢？

男性弱精症的病因可颇多，殖道感染、内分泌不足等都能造成男性弱精，引起男性弱精症原因：

1. 久坐，长时间坐着不运动，且久坐影响阴囊散热，不利于睾丸精；

2. 睾丸功能障碍，如：睾丸先天缺失、后天损伤，都会影响睾丸精功能；

3、抗抗体，抗抗体是常见免疫因素，抗抗体可以从不同的途径影响受精功能；

4. 内分泌激素不足，男性体内的内分泌激素是营养的主要来源，内分泌激素不足严重影响成长发育；

5. 其它药物影响，长期使用镇静剂、安眠药等会抑制成；

6. 抽烟喝酒，香烟中的尼古丁和酒中的酒精，都会损伤质量，造成少精症、弱精症、死精症等症状；

7. 精索静脉曲张，精索静脉曲张不仅仅对成造成影响，还会致使活力降低；

除此之外，精浆缺少锌、铜、镁等微量元素，缺乏酶或酶活性降低，性染色体畸变，不液化、粘稠度高，睾丸鞘膜腔积液，先天性纤毛结构缺乏，放射性照射，殖道、殖腺体感染等都会在无形中影响的活力。

如果治不好的话，活力低下可以做试管婴儿吗？是不是做试管率也会非常低，还是影响不大。

如果实在不能自然育，是可以选择试管婴儿的，随着科学技术的发展，试管婴儿已经从第一代的体外受精，经历第二代的卵泡内单注射技术，发展到第三代的辅助殖技术，应用胚胎着床前遗传病诊断，进行优选，以到达优优育的目的。只要有产，就是可以做试管婴儿的，只是相对于自然育的话，费用就会大大增加。轻度弱精症怀孕的几率还是很大的，只有重度弱精，活率基本为0的情况下，可以考虑选择试管婴儿。

我老公好像是轻度弱精症，因为之前怀过一次，那治疗好了的话，需要怎么预防呢？感觉他就是活习惯不太好，爱抽烟喝酒。

弱精症的预防：

1. 良好的活习惯：饮食健康规律、不熬夜，适当运动，平时注意个人卫；

2. 戒烟戒酒：烟、酒对的伤害是非常大的；

3. 少：长久性的会导致前列腺充血，引发前列腺炎症；

4. 远离高温环境，如：桑拿房、蒸汽房等地方，睾丸处于高温的话，会直接影响睾丸精功能，如果长期性的蒸浴的话，对男性性活会造成影响；

5. 多吃新鲜的蔬菜、水果，能够补充长发育所需营养。
