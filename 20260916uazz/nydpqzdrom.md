# 关节外科带你走进【AI新纪元】

> 更新时间：2026-09-16 (UTC+8)

随着我国老年人口逐年增多，膝关节骨关节炎的发病率逐年增加，**人工膝关节置换术**（total knee arthroplasty，TKA）已成为骨科手术中普及率极高的手术方式之一，TKA能最大程度恢复病变的膝关节功能，实现术后假体遗忘和假体长期使用是膝关节疾病患者和关节外科医生的共同追求。

然而，**膝关节假体旋转、尺寸匹配及下肢力线是术后患者关节舒适度和人工假体远期寿命的重要影响因素**。患者个体之间膝关节解剖结构及膝关节磨损情况存在差异，没有统一的截骨角度，而TKA手术截骨角度和厚度的偏差可能导致手术灾难性的结果。

因此，为实现术后下肢良好对线，**TKA术前有必要进行个性化的规划**，帮助术者选取合适型号的假体并施行个性化手术。

**Artificial Intelligence（AI）**在医疗领域有着广泛的应用。它既可辅助医生做出决策，又可协助改善患者健康。AI技术的逐渐发展与成熟，让其在人工关节置换术前规划、术中指导、术后康复、远程医疗以及基础研究等骨科领域都展示出巨大的前景。

8月18日，海南省人民医院关节外科林坚平主任带领其手术医师团队，在手术室团队的协助下，通过术前人工智能TKA手术三维规划系统，精准规划假体大小、位置及角度，顺利完成了三例TKA手术。

林坚平手术团队正在进行人工膝关节置换术

**病例介绍**

患者，男，71岁，因左膝关节疼痛不适6年余，加重1年入院

- 
**专科查体：**步入病室，左侧膝关节无明显肿胀，外观轻度内翻畸形。DR检查示“左膝关节在位，构成骨骨质疏松，关节面致密，胫骨平台边缘、股骨内髁、髌骨边缘及胫骨髁间隆起骨质增生，关节间隙不对称性狭窄”。

- 
**诊断：**左侧膝关节骨性关节炎。

**手术过程**

术前采集病人下肢全长负重站立位DR片、患侧膝关节正侧位DR，以及患侧膝关节CT影像。去除病人个人信息并签署知情同意书后，数据导入**AI KNEE系统**，快速智能生成并自动分割病人膝关节三维骨性解剖结构。

林坚平手术团队正在进行人工膝关节置换术

**软件自动识别解剖结构标志并测量膝关节关键参数：**股骨外旋角为3°、股骨后髁角3°、股骨远端截骨厚度9mm，胫骨平台后倾角3°、胫骨平台截骨厚度9mm。使用ATTUNE-PS固定平台假体，**AI KNEE系统据此智能生成手术方案**，股骨侧为ATTUNE-PS假体5号，胫骨侧选用ATTUNE-FB假体7号。

术中使用常规膝关节工具辅助完成手术，截骨角度与厚度根据AI KNEE手术方案执行，手术仅用时50分钟，**所用假体型号、截骨角度与术前规划完全一致**，内外侧间隙及屈伸间隙平衡，髌骨轨迹及关节活动度良好。

术后复查DR示假体位置良好，下肢力线恢复至中立位

现有膝关节术前规划方式分为两类，二维模板测量法和三维手工规划法。

二维模板测量法通过影像学测量下肢全长DR片，获取下肢力线及膝关节角度，为术者术中截骨提供假体大小、截骨角度等参考，但因DR线摄片过程中存在的不足，加之病人膝关节常存在屈曲挛缩畸形等情况，无法保证膝关节DR线正位、侧位片为标准的正侧位DR线片，常存在有扭转、重叠等情况发生，导致DR线片无法准确反映病人膝关节的实际情况，测量结果的误差较大，在假体型号预测方面的准确性较低。**近年来，为解决二维术前规划存在的问题，三维术前规划软件应运而生。**

本次手术首次使用基于人工智能的TKA手术三维规划系统进行术前规划，该系统可根据病人术前CT图像，精确地对骨骼关键解剖点位进行识别，识别精度接近毫米级。**依据假体设计理念及病人股骨、胫骨的解剖结构特点，帮助术者准确、快速、个性化地放置膝关节假体，计算最适角度，个性化制定病人三维术前规划，以最大限度恢复病人股骨旋转及下肢力线，提高病人术后满意度。**

病例中，术前规划的假体大小、角度和位置均与术中实际应用基本完全一致，与传统术前规划相比，该系统的优势体现**在术前规划由人工智能自动生成**。针对一些股骨严重畸形或残留内固定等影响髓内导向器使用的病例，在术前规划方案的基础上，可以进一步设计病人特异性截骨导航器械，精准辅助完成TKA手术。

**海南省人民医院关节外科**是本省率先开设的专注于关节疾患诊疗的专科之一，是海南省骨科重点专科、骨科医疗质量控制中心挂靠单位。在人工关节初次置换、翻修、保髋、保膝等领域具有丰富的经验和手术疗效满意度。在关节镜微创领域同样开展了肩袖损伤修复、膝关节交叉韧带重建、膝关节半月板损伤的修复等国内外先进的手术方式，并取得较高的手术疗效满意度。
