# 普丽康打针方法图解中是要将针头全按进去吗？

> 更新时间：2026-09-10 (UTC+8)

我促排用的是普丽康，但因为我家离医院太远了，而且去医院打针还要排队很久。去医院打了两次针后，我决定自己回家打针，这样省事很多。护士当时教了我该怎么打，但是有个点我没有注意，就是普丽康打针方法图解中是要将针头全按进去吗？

注射普丽康的时候不用将针头全部按入，只有进入2.5-3厘米即可。其实注射时对深度并没有太多的要求，主要是看其注射的位置，不能刺到重要的神经和血管，如果注射错误，很容易产生普丽康副作用。该药物既可以肌肉注射也可以皮下注射，主要看患者的病情选择相应的注射方式。一般注射在患者的肚子、大腿或是屁股这种人体脂肪比较多的位置。

普丽康是一种促排卵药物，它不仅能刺激卵巢中卵泡的发育，还能控制卵泡排出的时间，使医生在为患者做取卵手术时，能从女性卵巢中取出更多数量的优势卵泡，以此来提高试管婴儿成功率，对于卵巢有问题的女性，有必要注射这类针剂。该药物的注射方法具体如下：

- 1. 首先需要将注射器取出，采用高温消毒，在沸水中煮5分钟左右；
- 2. 将药瓶盖取下，用注射器将药瓶中的药液取出；
- 3. 准备绵花和摄子，用摄子取一些绵花粘一些消毒水；
- 4. 对身体上的注射部位进行消毒，再将针剂注射进身体；
- 5. 注射过程中要将注射器中的药剂打完，切记不可回抽；
- 6. 打完注射器中的药剂后，还需要对注射部位进行消毒。
做试管婴儿前注射普丽康的作用不仅仅是促排卵，此药还能提高移植成功率，所以女性一定要听从医生的医嘱定期按时完成这项操作。除此之外，注射普丽康的注意事项也有很多，注射时速度不易过快，还需要根据卵泡发育情况调整后期注射剂量等等。
